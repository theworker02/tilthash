# tilthash

Tilt numeric hash values, ranges, and human-readable units.

**Site:** https://theworker02.github.io/tilthash/

## Install / run

```bash
git clone https://github.com/theworker02/tilthash.git
cd tilthash
node src/cli.js
node --test
```
